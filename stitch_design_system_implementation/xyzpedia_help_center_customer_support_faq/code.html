help_center Saldo terpotong tapi status pembayaran masih menunggu? expand_more

Hal ini umumnya terjadi saat ada lonjakan traffic di jaringan perbankan atau QRIS Nasional (ASPI). Sistem XYZPEDIA secara berkala menyinkronkan status setiap 15 detik.

Tindakan Disarankan: Tunggu 1–3 menit lalu klik tombol Refresh Status di halaman pelacak pesanan. Jika dalam 5 menit belum berubah, kirim bukti mutasi rekening ke WhatsApp CS untuk approve manual secara instan.
help_center QRIS kadaluarsa saat sedang transfer? expand_more

Setiap kode QRIS memiliki masa berlaku aktif 15 menit demi alasan keamanan transaksi real-time. Jika Anda mentransfer setelah barcode expired, transaksi akan terhambat di status unmapped.

Jangan khawatir: Dana Anda tidak hilang. Silakan buat pesanan baru dan lampirkan bukti transfer dari invoice sebelumnya ke formulir klaim garansi untuk verifikasi instan.

help_center Cara bayar menggunakan Virtual Account bank lain? expand_more

Gunakan menu transfer antar bank (BI-FAST atau Online Transfer) lalu masukkan kode bank penyedia Virtual Account yang tertera di halaman checkout. Pastikan nominal pembayaran sama persis hingga digit terakhir tanpa pembulatan.

Sebagian besar top-up (Mobile Legends, Free Fire, PUBG Mobile, Valorant) diproses otomatis via API Publisher dalam tempo 5 hingga 60 detik setelah pembayaran dinyatakan lunas.

help_center Salah memasukkan User ID atau Zone ID? expand_more

Karena pengiriman dilakukan secara otomatis oleh sistem robotik seketika setelah pembayaran terverifikasi, transaksi yang sukses terkirim ke User ID tujuan tidak dapat ditarik kembali.

PENTING: Jika status pesanan masih "Menunggu Antrean Provider", segera kirim pesan darurat ke WhatsApp Concierge dengan menyertakan Nomor Invoice dan koreksi ID game yang tepat sebelum bot mengeksekusi data.
help_center Bukti pengiriman Moonton API hash? expand_more

Setiap transaksi top-up yang berhasil memiliki referensi unik Server Hash & Sequence Order dari server resmi publisher. Anda dapat menyalin kode ini di halaman Detail Invoice untuk klaim tiket ke Customer Support in-game bila diperlukan.
