1. Prinsip Pembelian Tamu (Guest-Direct)

XYZPEDIA beroperasi di bawah mandat arsitektur 100% Guest-Direct. Seluruh proses pemilihan voucher game, langganan digital, hingga konfirmasi pembayaran tidak pernah dan tidak akan pernah mewajibkan pembeli membuat akun kata sandi, verifikasi OTP registrasi rumit, maupun pengikatan kartu kredit.

info Komitmen Nir-Kredensial XYZPEDIA:

  • Kami TIDAK PERNAH menanyakan atau menyimpan kata sandi (password) akun game Moonton, Riot ID, Steam, maupun email pribadi pengguna.
  • Hanya User ID dan Zone/Server ID publik yang dibutuhkan untuk memvalidasi tujuan transfer top-up koin atau diamond.
  • Invoice digital diterbitkan secara independen berbasis Token Transaksi yang dapat dilacak pada menu Track Order tanpa histori akun tertanam.

Dengan mengeksekusi pesanan, pengguna menyetujui bahwa validitas User ID dan Server ID yang dimasukkan sepenuhnya merupakan tanggung jawab pengguna. Sistem otentikasi publisher otomatis kami akan memverifikasi nama karakter (In-Game Name) sebelum jendela pembayaran dibuka untuk meminimalisir kesalahan salah sasaran akun.
